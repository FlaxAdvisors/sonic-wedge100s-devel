# ORv2 RackMon RS-485 Power Shelf Monitoring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Use the three RS-485 RJ45 ports on the Wedge 100S-32X rear panel to monitor the Open Rack V2 power shelf health (rectifier status, DC output, fan speed, temperature, input AC) via the Facebook RackMon protocol. Expose rack-shelf telemetry as new SONiC platform observables: a `RackShelf` class surfaced through a new chassis method, and per-shelf cache files under `/run/wedge100s/rackmon_*` for system-health and external dashboards. Closes GAP-040.

**Architecture:** Four layers — **and `rackmond` is already running on the BMC.** Verified 2026-04-09: `/usr/local/bin/rackmond` (pid 721, 26 hr uptime) with its full CLI toolkit (`rackmonctl`, `rackmondata`, `rackmonscan`, `rackmonstatus`) and the runit service at `/etc/sv/rackmond/run` are shipped by stock Facebook OpenBMC. We don't fork, cross-compile, or push any new BMC binary. (1) We adapt `/etc/rackmon-config.py` on the BMC with the correct serial device + shelf register map for our hardware (config file only — the daemon binary is untouched). (2) `wedge100s-bmc-daemon` on the host queries `rackmonstatus`/`rackmondata` over the existing SSH ControlMaster on each 10-second tick and mirrors per-shelf telemetry into `/run/wedge100s/rackmon_shelf_<id>_{voltage_mv,current_ma,fan_rpm,temp_c,status}` cache files. (3) A new `RackShelf` Python class in `sonic_platform/rack_shelf.py` exposes the cache to SONiC platform API callers. (4) The ORv2 SKU detection from GAP-044 determines at runtime whether the host-side mirror runs at all — non-ORv2 platforms skip the entire path (even though rackmond is running on the BMC, there's no RS-485 bus to talk to on an AC SKU).

**Tech Stack:** Shell (push a one-file `rackmon-config.py` to the BMC + `sv restart`), C (host `wedge100s-bmc-daemon.c` extension to invoke `rackmonstatus`/`rackmondata` over SSH and parse output), Python 3 (sonic_platform `RackShelf` class + chassis integration), SSH ControlMaster (existing bmc-daemon infrastructure), pytest (SKU-gated hardware tests). **No** cross-compile, **no** new BMC binary, **no** bitbake recipe, **no** OpenBMC image rebuild, **no** `wedge100s/submodule-patches` branch touched.

**Platform fork prefix:** `/export/sonic/sonic-buildimage/platform/broadcom/sonic-platform-modules-accton/wedge100s-32x/`
**Devel repo prefix:** `/export/sonic/sonic-wedge100s-devel/`

**Key finding that shapes this plan (verified 2026-04-09):** Stock Facebook OpenBMC on Wedge100S ships `rackmond` and its entire toolkit. The daemon is actively running but reports empty output because no rack is connected (`Monitored PSUs: / Active on last scan: / Next scan in 60 seconds.`). All we need to do is feed it the right config (via `/etc/rackmon-config.py` — which the existing `/etc/sv/rackmond/run` executes at daemon startup) and consume its CLI output from the host.

**⚠️ Depends on GAP-044 plan.** This plan assumes `/run/wedge100s/sku` exists and reads as `orv2` on the ORv2 SKU — that file is written by the Task 2 work in `2026-04-09-orv2-ltc4151-bus-bar-telemetry.md`. - [ ] **Step 4: Add push-to-BMC logic in wedge100s-bmc-daemon.c**

Add a helper function (after the existing `bmc_connect()`) that rsyncs our config file to `/etc/rackmon-config.py` on the BMC and restarts the rackmond service:

```c
#define RACKMON_CONFIG_HOST_PATH \
    "/usr/share/sonic/device/x86_64-accton_wedge100s_32x-r0/bmc/rackmon-config.py"
#define RACKMON_CONFIG_BMC_PATH  "/etc/rackmon-config.py"

/**
 * @brief Push our rackmon-config.py to the BMC and restart rackmond.
 *
 * Only runs on ORv2 SKU (g_sku == SKU_ORV2 from the GAP-044 plan).
 * Uses the existing SSH ControlMaster to:
 *   1. rsync our rackmon-config.py to /etc/rackmon-config.py on the BMC
 *   2. sv restart rackmond (runit) to pick up the new config
 *
 * Non-fatal on failure — rackmond stays at the stock config (which
 * may still work depending on the rack) and we continue polling.
 *
 * @return 0 on success, -1 on failure.
 */
static int push_rackmon_config(void)
{
    char cmd[512];

    /* 1. Rsync the config file. */
    snprintf(cmd, sizeof(cmd),
        "rsync -e 'ssh -S " CTL_SOCK " -o BatchMode=yes' -q "
        RACKMON_CONFIG_HOST_PATH " " BMC_HOST ":" RACKMON_CONFIG_BMC_PATH);
    int rc = system(cmd);
    if (rc != 0) {
        syslog(LOG_WARNING, "rsync rackmon-config.py failed: rc=%d", rc);
        return -1;
    }

    /* 2. Restart rackmond via runit. */
    snprintf(cmd, sizeof(cmd),
        "ssh -S " CTL_SOCK " -o BatchMode=yes " BMC_HOST
        " 'sv restart rackmond 2>&1'");
    rc = system(cmd);
    if (rc != 0) {
        syslog(LOG_WARNING, "sv restart rackmond failed: rc=%d", rc);
        return -1;
    }

    syslog(LOG_INFO, "rackmon-config.py pushed and rackmond restarted");
    return 0;
}
```

- [ ] **Step 1: Add the poll helper**

After the existing `poll_ltc4151()` function (from GAP-044), add:

```c
/**
 * @brief Query rackmon CLI tools on the BMC and mirror output to cache files.
 *
 * Runs `rackmondata` over the existing SSH ControlMaster to get a
 * machine-readable dump of all discovered shelves, parses the output,
 * and writes per-shelf cache files:
 *
 *   /run/wedge100s/rackmon_shelf_<id>_voltage_mv
 *   /run/wedge100s/rackmon_shelf_<id>_current_ma
 *   /run/wedge100s/rackmon_shelf_<id>_fan_rpm
 *   /run/wedge100s/rackmon_shelf_<id>_temp_c
 *   /run/wedge100s/rackmon_shelf_<id>_status
 *
 * The exact `rackmondata` output format is captured in Task 1's
 * research notes. This function parses it with a simple strstr/sscanf
 * approach (no JSON lib dependency) because the output is from a
 * trusted daemon on a local SSH link.
 *
 * No-op on AC SKU; caller gates on g_sku == SKU_ORV2.
 */
static void poll_rackmon_shelves(void)
{
    char cmd[256];
    char buf[4096];

    /* Run rackmondata on the BMC and capture output. */
    snprintf(cmd, sizeof(cmd),
        "ssh -S " CTL_SOCK " -o BatchMode=yes " BMC_HOST
        " '/usr/local/bin/rackmondata 2>/dev/null'");
    FILE *fp = popen(cmd, "r");
    if (!fp) return;

    size_t n = fread(buf, 1, sizeof(buf) - 1, fp);
    pclose(fp);
    buf[n] = '\0';

    if (n < 4) return;  /* empty output (no shelves) */

    /* rackmondata typically returns a Python-repr or JSON list of
     * per-shelf dicts. Parse each shelf section by scanning for
     * known field markers.
     *
     * Example output format (from Task 1 research):
     *   [{"shelf_id": 0xA0, "voltage_mv": 11987, "current_ma": 12345,
     *     "fan_rpm": 8500, "temp_c": 35, "status": 0x0100}, ...]
     *
     * We avoid pulling in a JSON lib; sscanf+strstr is fine for
     * this trusted source.
     */
    const char *p = buf;
    while ((p = strstr(p, "shelf_id")) != NULL) {
        int shelf_id = -1, voltage_mv = 0, current_ma = 0;
        int fan_rpm = 0, temp_c = 0, status = 0;

        sscanf(p, "shelf_id\"%*[^0-9]%d",   &shelf_id);
        const char *q;
        if ((q = strstr(p, "voltage_mv")) != NULL)
            sscanf(q, "voltage_mv\"%*[^0-9]%d", &voltage_mv);
        if ((q = strstr(p, "current_ma")) != NULL)
            sscanf(q, "current_ma\"%*[^0-9]%d", &current_ma);
        if ((q = strstr(p, "fan_rpm")) != NULL)
            sscanf(q, "fan_rpm\"%*[^0-9]%d",    &fan_rpm);
        if ((q = strstr(p, "temp_c")) != NULL)
            sscanf(q, "temp_c\"%*[^0-9-]%d",    &temp_c);
        if ((q = strstr(p, "status")) != NULL)
            sscanf(q, "status\"%*[^0-9]%d",     &status);

        if (shelf_id >= 0 && shelf_id <= 255) {
            char path[128];
```

```python
#!/usr/bin/env python3
"""sonic_platform/rack_shelf.py — ORv2 rack power shelf observable.

On the ORv2 SKU, the Wedge 100S-32X talks to one or more rack-level
power shelves over RS-485 via the BMC-resident rackmond daemon
(platform/.../utils/rackmond/). Per-shelf status is mirrored to
/run/wedge100s/rackmon_shelf_<id>_{voltage_mv,current_ma,fan_rpm,
temp_c,status} by wedge100s-bmc-daemon.

RackShelf is a lightweight observable object (NOT a subclass of
PsuBase — a power shelf is a rack peer, not a chassis PSU). Callers
get a list of live RackShelf instances via a new chassis method
`get_all_rack_shelves()` added by the chassis integration task.

This file is imported only when /run/wedge100s/sku == 'orv2'; on
AC SKUs it is never loaded.
"""

import os
import time

_RUN_DIR = '/run/wedge100s'
_CACHE_TTL = 30.0


def _read_int(path):
    """Read a plain decimal integer from a host cache file.

    Args:
        path: Absolute path to the cache file.

    Returns:
        int or None: Parsed integer, or None on read/parse error.
    """
    try:
        with open(path) as f:
            return int(f.read().strip())
    except (IOError, OSError, ValueError):
        return None


def discover_rack_shelves():
    """Find all rack shelves reported by the BMC rackmond daemon.

    Scans /run/wedge100s/ for rackmon_shelf_<id>_voltage_mv files and
    returns the set of shelf IDs that have at least a voltage cache.
    An ID is included if the voltage file exists and is readable —
    non-existence means either (a) the shelf is absent or (b) rackmond
    hasn't discovered it yet.

    Returns:
        list[int]: Sorted list of discovered shelf IDs.
    """
    if not os.path.isdir(_RUN_DIR):
        return []

    shelves = set()
    for name in os.listdir(_RUN_DIR):
        if not name.startswith('rackmon_shelf_'):
            continue
        if not name.endswith('_voltage_mv'):
            continue
        # rackmon_shelf_<id>_voltage_mv → <id>
        middle = name[len('rackmon_shelf_'):-len('_voltage_mv')]
        try:
            shelves.add(int(middle))
        except ValueError:
            continue
    return sorted(shelves)


class RackShelf:
    """A single ORv2 rack power shelf observable.

    Not a PsuBase — rack shelves are rack-peer devices, not chassis
    PSUs. They are exposed via a new Chassis.get_all_rack_shelves()
    method and consumed by higher-level rack health observability
    (external dashboards, orchestration).
    """

    def __init__(self, shelf_id):
        """Initialize a rack shelf wrapper.

        Args:
            shelf_id: RackMon unit ID (1-15 typical range).
        """
        self._shelf_id = shelf_id
        self._cache = {}

    def _telemetry(self):
        """Read all five cache files and return a dict.

        Caches results for _CACHE_TTL seconds.

        Returns:
            dict: Keys 'voltage_mv', 'current_ma', 'fan_rpm', 'temp_c',
                'status', 'ts' — any of the first five may be absent.
        """
        now = time.monotonic()
        if self._cache.get('ts', 0) + _CACHE_TTL > now:
            return self._cache

        result = {'ts': now}
        for key, fname in (
            ('voltage_mv', 'voltage_mv'),
            ('current_ma', 'current_ma'),
            ('fan_rpm',    'fan_rpm'),
            ('temp_c',     'temp_c'),
            ('status',     'status'),
        ):
            path = '{}/rackmon_shelf_{}_{}'.format(_RUN_DIR, self._shelf_id, fname)
            val = _read_int(path)
            if val is not None:
                result[key] = val

        self._cache = result
        return result

    def get_id(self):
        """Return the RackMon unit ID of this shelf."""
        return self._shelf_id

    def get_name(self):
        """Return a SONiC-visible name."""
        return 'RackShelf-{}'.format(self._shelf_id)

    def get_presence(self):
        """Return True if any telemetry was readable in the last cycle.

        A shelf that stops responding on RS-485 (rackmond marks it
        absent) will have stale or missing cache files.
        """
        return 'voltage_mv' in self._telemetry()

    def get_voltage(self):
        """Return the shelf output voltage in volts, or None."""
        mv = self._telemetry().get('voltage_mv')
        return None if mv is None else mv / 1000.0

    def get_current(self):
        """Return the shelf output current in amperes, or None."""
        ma = self._telemetry().get('current_ma')
        return None if ma is None else ma / 1000.0

    def get_power(self):
        """Return derived power in watts, or None.

        Power is computed from voltage × current rather than read
        from a separate cache file because rackmond doesn't publish
        a power field uniformly across shelf models.
        """
        v = self.get_voltage()
        i = self.get_current()
        if v is None or i is None:
            return None
        return v * i

    def get_fan_rpm(self):
        """Return the shelf fan speed in RPM, or None."""
        return self._telemetry().get('fan_rpm')

    def get_temperature(self):
        """Return the shelf internal temperature in °C, or None."""
        return self._telemetry().get('temp_c')

    def get_status_word(self):
        """Return the shelf status word (vendor-specific bit field), or None.

        Decoding the bits is left to the caller — the bit map varies
        by power shelf vendor. The raw integer is exposed so upstream
        observability can store and query it.
        """
        return self._telemetry().get('status')

    def get_status(self):
        """Return True if the shelf is present and voltage is in 10-14 V range.

        Conservative health check — rack shelves nominally run 12V DC
        output, similar to chassis bus-bar input. Exact thresholds
        depend on the rack shelf model; 10-14 V covers the typical
        ±15% tolerance. Vendors that require tighter limits should
        replace this method via subclassing.
        """
        v = self.get_voltage()
        if v is None:
            return False
        return 10.0 <= v <= 14.0
```

```python
        "\n\nCheck wedge100s-bmc-daemon poll_rackmon_shelves() and "
        "the BMC /var/lib/rackmon/ directory for fresh JSON files."
```

```python
"""Stage 06 supplement — RackShelf platform API (GAP-040).

Exercises chassis.get_all_rack_shelves() on ORv2 SKUs and verifies
each returned RackShelf object's methods produce plausible values.
Skips on AC SKU.

import json
import pytest

SKU_FILE = "/run/wedge100s/sku"

CAPTURE = """\
import json
from sonic_platform.platform import Platform
chassis = Platform().get_chassis()
shelves = chassis.get_all_rack_shelves() if hasattr(chassis, "get_all_rack_shelves") else []
results = []
for s in shelves:
    results.append({
        "id": s.get_id(),
        "name": s.get_name(),
        "present": s.get_presence(),
        "voltage": s.get_voltage(),
        "current": s.get_current(),
        "power": s.get_power(),
        "fan_rpm": s.get_fan_rpm(),
        "temperature": s.get_temperature(),
        "status_word": s.get_status_word(),
        "status": s.get_status(),
    })
print(json.dumps(results))
"""


def _read_sku(ssh):
    out, _, rc = ssh.run(f"cat {SKU_FILE}", timeout=5)
    return out.strip() if rc == 0 else None


def _capture(ssh):
    out, err, rc = ssh.run_python(CAPTURE, timeout=30)
    assert rc == 0, f"rack shelf capture failed: {err}"
    return json.loads(out.strip())


def test_rack_shelf_skipped_on_ac_sku(ssh):
    """On AC SKU, get_all_rack_shelves returns an empty list."""
    sku = _read_sku(ssh)
    if sku == "ac":
        shelves = _capture(ssh)
        assert shelves == [], (
            f"AC SKU should return no rack shelves, got {shelves}"
        )
        pytest.skip("AC SKU — no shelves to test (expected)")


def test_rack_shelf_list_populated(ssh):
    """On ORv2 SKU, at least one shelf is returned (if a rack is connected)."""
    sku = _read_sku(ssh)
    if sku != "orv2":
        pytest.skip("Not an ORv2 SKU")

    shelves = _capture(ssh)
    if not shelves:
        pytest.skip(
            "No rack shelves discovered. Either no rack is connected or "
            "rackmond discovery hasn't run yet."
        )
    for s in shelves:
        print(f"  {s['name']}: v={s['voltage']} i={s['current']} "
              f"fan={s['fan_rpm']} t={s['temperature']}")


def test_rack_shelf_names_unique(ssh):
    """Shelf names are unique (one RackShelf per unit ID)."""
    sku = _read_sku(ssh)
    if sku != "orv2":
        pytest.skip("Not an ORv2 SKU")

    shelves = _capture(ssh)
    if not shelves:
        pytest.skip("No shelves")
    names = [s['name'] for s in shelves]
    assert len(names) == len(set(names)), (
        f"Duplicate shelf names: {names}"
    )


def test_rack_shelf_voltage_in_range(ssh):
    """All present shelves report voltage in 10-14 V."""
    sku = _read_sku(ssh)
    if sku != "orv2":
        pytest.skip("Not an ORv2 SKU")

    shelves = _capture(ssh)
    if not shelves:
        pytest.skip("No shelves")
    for s in shelves:
        if not s['present']:
            continue
        v = s['voltage']
        assert v is not None, f"{s['name']}: voltage is None but present=True"
        assert 10.0 <= v <= 14.0, f"{s['name']}: voltage={v} outside 10-14 V"


def test_rack_shelf_power_derived_consistent(ssh):
    """get_power() matches voltage * current within ±5%."""
    sku = _read_sku(ssh)
    if sku != "orv2":
        pytest.skip("Not an ORv2 SKU")

    shelves = _capture(ssh)
    if not shelves:
        pytest.skip("No shelves")
    for s in shelves:
        v, i, p = s['voltage'], s['current'], s['power']
        if v is None or i is None or p is None:
            continue
        expected = v * i
        tolerance = max(expected * 0.05, 5.0)
        assert abs(p - expected) <= tolerance, (
            f"{s['name']}: power={p} W does not match v*i={expected} W "
            f"(tolerance {tolerance} W)"
        )
```

```markdown
### ORv2 RackMon power shelf monitoring

On the ORv2 SKU, three RS-485 RJ45 connectors on the rear panel provide
the RackMon multi-drop bus that the rack-level power shelves publish
on. The BMC runs a forked version of Facebook's `rackmond` daemon
(source at `platform/broadcom/sonic-platform-modules-accton/
wedge100s-32x/utils/rackmond/`) that discovers power shelves by
scanning RackMon unit IDs, polls each one on a configurable cadence
(default 5 s), and writes per-shelf status JSON to
`/var/lib/rackmon/shelf_<id>.json`.

`wedge100s-bmc-daemon` on the host tails those JSON files over its
existing SSH ControlMaster and mirrors the integer fields to:

- `/run/wedge100s/rackmon_shelf_<id>_voltage_mv`
- `/run/wedge100s/rackmon_shelf_<id>_current_ma`
- `/run/wedge100s/rackmon_shelf_<id>_fan_rpm`
- `/run/wedge100s/rackmon_shelf_<id>_temp_c`
- `/run/wedge100s/rackmon_shelf_<id>_status`

The SONiC platform API exposes these via a new
`chassis.get_all_rack_shelves()` method returning a list of
`RackShelf` objects. `RackShelf` is NOT a `PsuBase` subclass — rack
shelves are rack-peer devices, not chassis PSUs — so SONiC
system-health treats them separately from the `get_all_psus()` path.
On the AC SKU, `get_all_rack_shelves()` always returns an empty list.

The forked `rackmond` preserves the upstream GPL-2.0 license. The
re-sync procedure for pulling future upstream fixes is documented
in `platform/.../utils/rackmond/README.wedge100s.md`. The RackMon
protocol details (baud, framing, CRC, register maps) are in
`notes/2026-04-09-rackmon-research.md`.
```
